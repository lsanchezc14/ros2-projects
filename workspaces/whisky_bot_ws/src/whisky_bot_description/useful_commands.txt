A dlopen error for libsdformat14.so.14 in ROS 2 happens when a plugin or node (like RViz, Gazebo integration, or robot description packages) tries to dynamically load SDFormat 14, but the system dynamic linker cannot find the shared library file in standard search paths

source /opt/ros/$ROS_DISTRO/setup.bash
export LD_LIBRARY_PATH=/opt/ros/$ROS_DISTRO/lib:$LD_LIBRARY_PATH
export LD_PRELOAD=/usr/lib/x86_64-linux-gnu/libsdformat14.so.14
